Sound design: only real-world moments make a sound. Two rings while the call comes in, a
call-connected tone on Accept and a call-ended tone on End call. In-phone screen slides are silent;
a whoosh marks only the jump from phone to desktop and back. Keyboard clicks while the reply types
into the open keypad, and a sent sound as the keypad closes and the message lands. A chime on
"Auto-logged to CRM", quiet typing under the live transcript and the summary. The music ducks under
each line; the mix is normalised to −14 LUFS.

Notes: "forty calls a day" is a benchmark, not a measured figure. Swap it if you have Meson's own
number. "In minutes" stays deliberately vague; only say "two minutes" if that's true at launch.
